# Welcome to Star Wars API Data Retriever! :globe_with_meridians:

Star Wars API Data Retriever retrieves the data you want from the Star Wars API **swapi** and displays the data of\
your choice, giving you the information you want to know about.

**Make sure when entering the inputs, write exactly how they are typed from the options as it is case-sensitive!**

#
## How to interact with Star Wars API Data Retriever :robot:

The system will prompt you to chose from a choice of 7 categories:
* films
* people
* planets
* species
* starships
* vehicles
* none

After you have chosen a category, you will be prompted to chose what information from the category of your choice you\
would like to know about e.g. choosing the category **people** will prompt you to choose from a list of characters you\
would like to know the details of.

Using the category **people** as an example, if you would like to know the information about more than one character in\
the options you have, the system will ask if you would like to, and if yes, will let you know information for more characters.

If not, the system will ask if you would like to know information about the other categories, and if yes, you would be\
able to access the data from the other categories and for more than one element within those categories if you would like\
to. If you have decided that you are done using Star Wars API Data Retriever, simply either choose the **none** option\
from the categories menu or say **no** twice to the questions asking if you would like to know more information about the\
category or other categories, and the system will close.

## Creative Scenario :notebook:

Create a program where I can retrieve data from the Star Wars API, store the data in a data structure, and create a\
user interactive system where they can choose what parts of the data they want to view. Give the user the choice on\
whether they want to find out about more of the data in a particular category, and if not, return to the main menu screen\
where all the categories are listed again. If the user doesn't want to select any more categories, give them this option\
and end the program with a goodbye message.
